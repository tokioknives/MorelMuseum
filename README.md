# The AI Museum

A living digital art space: an AI curator, an ever-changing gallery, a retro
internet community, and a shared VR world — built in the open, free for
everyone, and funded by donations.

## What's here right now

This is the starting point — a single landing page describing the project:

- `index.html` — the page content
- `style.css` — the retro-cyberspace visual style
- `script.js` — a small typing effect on the hero line

## Running it locally

No build tools needed yet. Just open `index.html` in a browser, or serve it
locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Roadmap

1. **Foundation** — this landing page + repo structure (you are here)
2. **Core museum** — password access, profiles, galleries, the AI curator's first pieces
3. **Community** — retro chat rooms, submissions, moderation, direct messages
4. **VR Room** — avatars, live presence, AI-generated music with a shared playlist
5. **AR layer** — mobile/AR-glasses experiences that extend the museum into the real world
